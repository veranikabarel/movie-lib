# 🎬 Movie Library

A simple movie library application built as a recruitment task.  
The app allows users to **search for movies, add them to their library, and remove them from the list**.

The project demonstrates modern frontend development using **React, TypeScript, and Vite**, along with state management, server state handling, and persistent storage.

## 🚀 Features

- 🔎 Search for movies
- ➕ Add movies to your personal library
- ❌ Remove movies from the list
- 💾 Persistent state (saved between page reloads)
- ⚡ Fast development environment with Vite
- 🎨 Styled using TailwindCSS

## 🛠 Tech Stack

### Core
- React 19
- TypeScript
- Vite

### State Management
- Redux Toolkit
- React Redux
- Redux Persist

### Server State
- TanStack React Query

### Routing
- React Router

### Styling
- TailwindCSS
